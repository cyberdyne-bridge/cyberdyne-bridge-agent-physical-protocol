# v1.7.5 — MCP Definition Pin Fix

## 安全修复

`drivers/mcp_device/driver.py` 的 MCP tool pin 以前只覆盖：

```text
name
description
inputSchema
annotations
```

并以 `json.dumps(sort_keys=True)` 计算，漏掉：

```text
title
outputSchema
icons
serverInfo.name / version
instructions
同连接 tools/list 变化
```

现在改为：

```text
完整 tool object
serverInfo.name + version
instructions（缺失 = 空串）
tools 按 name 排序
RFC 8785 JCS
SHA-256 + domain separator
旧 pin fail closed
每次动作前重新拉取 tools/list 校验
```
